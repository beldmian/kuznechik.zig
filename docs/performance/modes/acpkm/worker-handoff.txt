Rules and limits
  All sizes in BYTES, including section size and master lifetime (RFC uses bits).
  Section size positive multiple of16. Lifetime positive, divisible by16 and d.
  d = key bytes, except OMAC d = key bytes +16.
  Non-master CTR permits 2^(c-1) blocks; master CTR permits 2^c blocks.
  GCM reserves first two counters; matching non-master/master counter ranges.
  GCM AAD/payload lengths must fit64-bit bit-length fields.
  Master's complete section materials cannot exceed16 * 2^63 bytes.
  GCM tag sizes4,8,12..16 bytes; OMAC verification accepts1..16-byte prefixes.
  CBC requires full blocks; no implicit padding; empty streaming calls are no-ops.
  OMAC empty message uses one padded block under the first section material.
  Every failing preflight preserves data and context. Auth failures preserve
  ciphertext: verify first, decrypt second. AEAD seal rejects AAD/data,
  tag-output/data and tag-output/AAD overlap. Open rejects AAD/data and
  tag-input/data overlap. Empty/adjacent slices are permitted.
